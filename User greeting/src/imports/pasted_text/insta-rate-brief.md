Create a modern responsive web application called **InstaRate** — an AI-powered Instagram Profile & Feed Rater.

## CORE CONCEPT

InstaRate allows users to analyze their Instagram profile and feed.

The user will:

1. Paste their Instagram profile URL.
2. Upload a screenshot of their Instagram profile.
3. Upload one or more screenshots of their Instagram feed.
4. Click "Analyze My Profile".
5. See an AI-generated Instagram rating with scores, explanations, strengths, weaknesses, and recommendations.

IMPORTANT:
This is an Instagram-inspired application, NOT an exact Instagram clone. Use Instagram's familiar visual language while creating an original UI and branding for InstaRate.

Brand tagline:

**"Rate your feed. Improve your vibe."**

# IMPORTANT UX RULES

Do not make the application look like a generic admin dashboard.

Do not use excessive tables.

Do not make it look corporate.

The interface should feel like a modern social media application combined with an AI analytics tool.

Use visual hierarchy heavily.

The overall experience should feel:

**Instagram-inspired + AI-powered + Premium + Fun + Modern**

Make the result dashboard the visual centerpiece of the entire application.

Use realistic placeholder data and placeholder images so the application looks complete even before the backend and AI are connected.

Build all screens as a connected responsive application with consistent navigation and reusable components.
